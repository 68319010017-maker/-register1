NOVA MEMBER — ระบบสมัครสมาชิก PHP + MySQL
==========================================

ไฟล์ในโปรเจกต์
- db.php         เชื่อมต่อ MySQL ด้วย PDO
- register.php   ฟอร์มสมัครสมาชิก ตรวจสอบข้อมูล และบันทึกสมาชิก
- style.css      ธีม Dark Premium พร้อมแอนิเมชันและรองรับมือถือ
- database.sql   สร้างฐานข้อมูลและตาราง members

วิธีติดตั้งบน XAMPP
1. แตก ZIP
2. นำโฟลเดอร์ member_system_modern ไปไว้ที่ C:\xampp\htdocs\
3. เปิด XAMPP แล้ว Start Apache และ MySQL
4. เข้า http://localhost/phpmyadmin
5. เลือกแท็บ Import แล้วนำเข้าไฟล์ database.sql (หรือเปิดแท็บ SQL แล้ววางเนื้อหา)
6. หาก MySQL มีรหัสผ่าน ให้แก้ $dbpass ใน db.php
7. เปิด http://localhost/member_system_modern/register.php

ฟีเจอร์ตัวอย่าง
- ตรวจสอบข้อมูลที่จำเป็นและรูปแบบชื่อผู้ใช้
- ตรวจสอบชื่อผู้ใช้/อีเมลซ้ำ
- เข้ารหัสรหัสผ่านด้วย password_hash()
- PDO Prepared Statements และ CSRF token
- ปุ่มแสดง/ซ่อนรหัสผ่าน
- แถบประเมินความซับซ้อนของรหัสผ่าน
- ตรวจสอบว่ารหัสผ่านยืนยันตรงกัน
- แอนิเมชันเข้าใช้งาน การ์ดลอย แสงพื้นหลัง และเอฟเฟกต์ปุ่ม
- รองรับหน้าจอมือถือและตั้งค่าลดการเคลื่อนไหวของระบบ

หมายเหตุ
- ตัวอย่างนี้มีเฉพาะระบบสมัครสมาชิก ยังไม่มี Login/Logout
- ยังต้องทดสอบบนเครื่อง XAMPP จริงก่อนใช้งาน
- ก่อนนำขึ้นระบบจริง ควรเพิ่ม HTTPS, rate limiting, การยืนยันอีเมล และกำหนดสิทธิ์ฐานข้อมูลอย่างเหมาะสม
